# Cómo usar este manual

Este documento de **ejemplo** usa todos los elementos del formato. Sirve para comprobar que Word y PDF salen bien. Las imágenes son *muestras*, no capturas reales.

Lea los capítulos en orden. Cuando vea una tecla, como `F12`, búsquela en el teclado de la computadora.

## Qué necesita

- Una computadora con **Windows**.
- Su **usuario** y su **contraseña**.
- La balanza conectada y encendida.

## Cómo se escriben los pasos

Los pasos se numeran solos. Cada paso es **una sola acción**.

# Entrar al sistema

## Iniciar sesión

Siga estos pasos cada vez que empiece a trabajar.

1. Abra **Capataz** desde el escritorio.
2. Escriba su **Usuario** (recuadro **1**) y su **Contraseña** (recuadro **2**).

   ![Pantalla Iniciar sesión (imagen de muestra)](capturas/muestra-01-login.png){callouts=1,2,3}

3. Pulse el botón **Ingresar** (círculo **3**) o presione `Enter`.
4. Si el sistema se lo pide, escriba una contraseña nueva y pulse `Tab` para pasar al siguiente campo.

> [!IMPORTANTE]
> No comparta su contraseña con nadie. Cada persona debe entrar con su propio usuario.

> [!SI-ALGO-SALE-MAL]
> Si aparece el mensaje **Usuario o contraseña incorrectos.**:
>
> 1. Revise que las mayúsculas estén apagadas.
> 2. Vuelva a escribir la contraseña.
> 3. Si sigue sin entrar, consulte a su administrador del sistema.

> [!CONSEJO]
> Puede pasar de un campo a otro con la tecla `Tab` en lugar de usar el mouse.

# Registrar un pesaje

## Teclas que usará

| Tecla | Para qué sirve |
| :--- | :--- |
| `F5` | Captura el peso del lado izquierdo |
| `F6` | Captura el peso del lado derecho |
| `F8` | **Borrar pesaje** |
| `F12` | **Grabar** el pesaje |
| `Ctrl+P` | Imprimir la boleta |

## Lista con detalles

1. Elija el **Ganadero**.

   Escriba las primeras letras y use las flechas del teclado para elegir.

2. Elija el **Cliente**.
3. Haga lo siguiente en orden:
   - Espere a que la balanza muestre **ESTABLE**.
   - Pulse `F5`.
4. Pulse `F12` para grabar.

# Glosario {glosario}

- **Boleta**: documento impreso que respalda un pesaje. Tiene un número único.
- **Res completa**: animal faenado entero, que se pesa en dos lados.
- **Media res**: la mitad de un animal faenado.
- **Ganadero**: persona que entrega los animales para faenar.
- **Fletero**: persona que transporta la carne.
- **Código**: número que el sistema asigna solo a cada ganadero, cliente o fletero.

# Hoja de teclas rápidas {teclas}

Imprima esta hoja y péguela junto a la balanza.

## Al pesar

| Tecla | Qué hace |
| :--- | :--- |
| `F5` | Captura el peso del **lado izquierdo** |
| `F6` | Captura el peso del **lado derecho** |
| `F8` | **Borrar pesaje** y empezar de nuevo |
| `F12` | **Grabar** el pesaje |
| `F9` | Imprimir el último pesaje |

## En cualquier pantalla

| Tecla | Qué hace |
| :--- | :--- |
| `Enter` | Pasa al siguiente campo o acepta |
| `Esc` | Cancela o cierra la ventana |
| `Alt+F4` | Cierra el programa |

> [!IMPORTANTE]
> Si la balanza no está en **ESTABLE**, no se puede capturar el peso.
